# Assets

仓库级视觉资产位于 `assets/branding/`。主标识为不含字母的黑白 DockLayout 几何图标，通过 Tab 条、左右工具窗口、中央编辑器和底部区域表达停靠布局。

- `docklayout-icon.svg`：网站和文档主图标。
- `docklayout-icon-transparent.svg`：透明背景版本。
- `docklayout-icon-inverse.svg`：深色背景版本。
- `docklayout-icon-128.png`：NuGet `PackageIcon`。
- `docklayout-icon-32/64/256/512.png`：favicon、UI 和 PWA。

RCL 的运行时 CSS/JS 位于 `src/XLib.DockLayout/wwwroot`；Playground 使用的副本位于 `samples/DockLayout.Playground/wwwroot/icons`。
