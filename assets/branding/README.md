# DockLayout branding assets

The primary mark is a monochrome docking workspace. It deliberately contains no letters: the top tab strip, left/right tool windows, central editor and bottom panel identify the component as a docking-layout library at small sizes.

| File | Purpose |
|---|---|
| `docklayout-icon.svg` | Primary black-on-white website/documentation icon |
| `docklayout-icon-transparent.svg` | Black mark on a transparent background |
| `docklayout-icon-inverse.svg` | White mark on a black background |
| `docklayout-icon-32.png` | Browser favicon fallback |
| `docklayout-icon-64.png` | Compact UI asset |
| `docklayout-icon-128.png` | NuGet `PackageIcon` |
| `docklayout-icon-256.png` | Website/PWA asset |
| `docklayout-icon-512.png` | High-resolution PWA/social source |

The source SVG is the authoritative asset. PNG files are deterministic renders generated with CairoSVG.
